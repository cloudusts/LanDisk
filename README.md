# LanDisk

### A lightweight LAN file sharing tool

## How to use

1. Put files in to ./Files folder

2. Run server

~~~sh
node index.js
~~~

## Custom port and

~~~sh
node index.js --port 8080
node index.js --addr 127.0.0.1 --port 3000
node index.js --addr 127.0.0.1
~~~

## Something important

You should allow LAN access in firewall
